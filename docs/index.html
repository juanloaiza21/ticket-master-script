Find out when Ticketmaster lists new events, announces on-sale times, or changes an event's status for an artist, or when a ticketing page changes. Runs entirely in your browser; your key is only ever sent to Ticketmaster.

Colombia (and sites the API doesn't cover)

Ticketmaster's API has no Colombian events, but the Colombian sites do. A web page isn't allowed to read those sites directly, so you run a tiny free "page proxy" once and this page watches them through it.

In the Cloudflare editor click inside the code, press Ctrl+A and Delete so nothing is left, then paste. Two copies of the code in one file is the most common cause of errors.

The proxy can only fetch ticketmaster.co and latiquetera.com, only for this site, and never sees your API key. Hosting this page somewhere other than juanloaiza21.github.io? Add a Worker variable ALLOWED_ORIGINS. If a page says it is blocked, or "very little text came back", that site isn't giving its content to a proxy: use the browser userscript for that page instead (needs Tampermonkey).
